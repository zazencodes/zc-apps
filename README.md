# zc-apps

Small desktop apps by [ZazenCodes](https://zazencodes.com/). Each app lives in its own folder and builds from source.

| App | What it does |
| --- | --- |
| [Tier List ZC](tierlist/) | Drag-and-drop tier list app for macOS that your AI agent can build and edit for you. |
| [CPU Bars](cpu-bars/) | Menu bar CPU monitor for macOS. |
